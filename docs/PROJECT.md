# Project Definition

## Project

Hydra Public Research & Development Workspace

## Started

22 September 2026 as the dedicated GitHub research workspace. Earlier research activity from 21 September 2026 is preserved as project history.

## Current status

The repository is public and GitHub Pages publishes the research guide from `main`.

## Objectives

1. Maintain a reproducible Windows development environment.
2. Understand Hydra's architecture and runtime behavior.
3. Separate Hydra behavior from third-party integrations.
4. Perform controlled defensive security observations.
5. Keep an auditable research diary and evidence trail.
6. Preserve evidence without committing secrets or sensitive raw data.
7. Maintain a public guide that accurately reflects repository state.
8. Provide a reliable handoff structure so future AI assistants can continue the work without hidden conversation context.

## Non-objectives

This workspace is not intended to:

- claim that Hydra is safe or malicious without evidence
- distribute unauthorized copyrighted software
- bypass DRM or licensing controls
- publish private credentials or sensitive logs
- represent independent research as official Hydra statements

## Working principle

**Measure first. Hypothesize second. Verify before concluding.**

See `docs/PROJECT-MEMORY.md` for persistent project memory and operating rules.

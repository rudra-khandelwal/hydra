# Upstream Tracking

The upstream project is:

`hydralauncher/hydra`

This directory documents the relationship between the private research workspace and upstream.

The intended Git remotes for the local checkout are:

```text
origin   https://github.com/rudra-khandelwal/hydra.git
upstream https://github.com/hydralauncher/hydra.git
```

When syncing upstream, record the source commit and review the resulting diff.

Do not silently overwrite local research changes.

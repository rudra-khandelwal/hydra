# Contributing

This repository is currently a personal private research workspace.

## Change discipline

Prefer small, traceable changes.

Before committing:

1. Check the working tree.
2. Review the diff.
3. Remove secrets and personal data.
4. Record the reason for the change.
5. Run the relevant build/test command.
6. Update research documentation when a change affects the research methodology or findings.

## Research entries

Use:

**Fact → Observation → Hypothesis → Finding → Next Action**

Clearly label whether a statement is an observation, an inference, or a verified finding.

## Attribution

When preserving AI-assisted work, identify the source as [CHATGPT] or [CLAUDE] where the distinction matters.

## Commit messages

Prefer:

- `docs: ...`
- `research: ...`
- `security: ...`
- `build: ...`
- `fix: ...`
- `chore: ...`
